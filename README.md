# StockBar Releases

StockBar 的公开 macOS 二进制发布仓库，只保存安装包、版本信息和发行说明，不包含源码及开发配置。StockBar 应用使用这里的 GitHub Releases API 自动检查新版本。

## 安装

1. 从 Releases 下载最新的 `StockBar-版本号.dmg`。
2. 打开 DMG。
3. 将 `StockBar.app` 拖入 `Applications`。

## 完整性校验

每个版本的发行说明会提供 DMG 的 SHA-256。

## 签名状态

当前安装包使用 ad-hoc 签名且尚未经过 Apple 公证，首次打开时 macOS 可能显示无法验证开发者提示。
